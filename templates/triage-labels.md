# 分类标签

技能使用五类标准分类角色。本文件将这些角色映射到本仓库问题追踪器中实际使用的标签字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该问题  |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 需求已完整定义，可供 AFK 智能体处理  |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现            |
| `wontfix`                  | `wontfix`            | 不会处理                     |

当技能提到某个角色（例如「应用 AFK 就绪分类标签」），请使用本表中对应的标签字符串。

可根据实际使用的术语调整内容。

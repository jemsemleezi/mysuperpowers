# Engineering Skills
Daily code work skills for AI coding agents.

- [brainstorming](brainstorming/SKILL.md): Explores user intent and requirements before any creative work.
- [writing-plans](writing-plans/SKILL.md): Creates implementation plans from specs or requirements before coding.
- [executing-plans](executing-plans/SKILL.md): Executes written implementation plans with review checkpoints.
- [subagent-driven-development](subagent-driven-development/SKILL.md): Executes implementation plans with independent tasks using subagents.
- [dispatching-parallel-agents](dispatching-parallel-agents/SKILL.md): Dispatches 2+ independent tasks to parallel subagents.
- [tdd](tdd/SKILL.md): Enforces test-first development for all features and bugfixes.
- [diagnose](diagnose/SKILL.md): Structured debugging workflow for bugs and test failures.
- [grill-with-docs](grill-with-docs/SKILL.md): Generates and updates CONTEXT.md and ADRs from project documentation.
- [zoom-out](zoom-out/SKILL.md): Provides high-level project overview and architectural context.
- [to-prd](to-prd/SKILL.md): Converts feature requests into structured Product Requirement Documents (PRDs).
- [to-issues](to-issues/SKILL.md): Breaks PRDs into actionable, trackable issues.
- [triage](triage/SKILL.md): Prioritizes and categorizes issues in the issue tracker.
- [setup-project](setup-project/SKILL.md): Initializes new projects with standard tooling and configuration.
- [prototype](prototype/SKILL.md): Creates quick, functional prototypes to validate ideas.
- [verification-before-completion](verification-before-completion/SKILL.md): Verifies work with evidence before claiming completion.
- [improve-codebase-architecture](improve-codebase-architecture/SKILL.md): Refactors and improves overall codebase architecture and structure.

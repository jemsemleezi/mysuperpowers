# 工程类技能（Engineering Skills）
AI 编码代理的日常开发工作技能。

- [brainstorming](brainstorming/SKILL.md)：在任何创作性工作开始前，探索用户意图和需求。
- [writing-plans](writing-plans/SKILL.md)：在编码前，根据规格说明或需求创建实现计划。
- [executing-plans](executing-plans/SKILL.md)：在审查检查点的护航下，执行已写好的实现计划。
- [subagent-driven-development](subagent-driven-development/SKILL.md)：使用子代理，以独立任务的方式执行实现计划。
- [dispatching-parallel-agents](dispatching-parallel-agents/SKILL.md)：将 2 个或更多独立任务分派给并行子代理。
- [tdd](tdd/SKILL.md)：对所有功能和 Bug 修复强制执行测试优先开发。
- [diagnose](diagnose/SKILL.md)：面向 Bug 和测试失败的结构化调试流程。
- [grill-with-docs](grill-with-docs/SKILL.md)：基于项目文档生成并更新 CONTEXT.md 和 ADR。
- [zoom-out](zoom-out/SKILL.md)：提供项目高层概览与架构上下文。
- [to-prd](to-prd/SKILL.md)：将功能需求转换为结构化的产品需求文档（PRD）。
- [to-issues](to-issues/SKILL.md)：将 PRD 拆解为可执行、可跟踪的问题（issues）。
- [triage](triage/SKILL.md)：对问题跟踪器中的问题进行优先级排序和分类。
- [setup-project](setup-project/SKILL.md)：使用标准工具链和配置初始化新项目。
- [prototype](prototype/SKILL.md)：创建快速、可运行的原型以验证想法。
- [verification-before-completion](verification-before-completion/SKILL.md)：在宣称完成之前，用证据验证工作成果。
- [improve-codebase-architecture](improve-codebase-architecture/SKILL.md)：重构并改进整体代码库的架构与结构。

# 技能设计中的说服原则

## 概述

大语言模型（LLM）对人类使用的说服原则同样有反应。理解这一心理学原理能帮助你设计更有效的技能——不是为了操纵，而是确保关键实践即使在压力下也能被遵守。

**研究基础：** Meincke 等人（2025）在 28000 次 AI 对话中测试了 7 种说服原则。说服技术使合规率提升了一倍以上（33% → 72%，p < 0.001）。

## 七大原则

### 1. 权威原则
**定义：** 对专业知识、资质或官方来源的服从。

**在技能中的应用：**
- 祈使语气：“你必须”、“绝不”、“总是”
- 不可协商的表述：“没有例外”
- 消除决策疲劳和合理化借口

**使用场景：**
- 强制执行规范的技能（如 TDD、验证要求）
- 安全关键型实践
- 成熟的最佳实践

**示例：**
```markdown
✅ Write code before test? Delete it. Start over. No exceptions.
❌ Consider writing tests first when feasible.
```

### 2. 承诺原则
**定义：** 与先前的行动、陈述或公开声明保持一致。

**在技能中的应用：**
- 要求声明：“宣布使用的技能”
- 强制明确选择：“选 A、B 还是 C”
- 使用跟踪工具：用 TodoWrite 管理检查清单

**使用场景：**
- 确保技能被实际遵守
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ When you find a skill, you MUST announce: "I'm using [Skill Name]"
❌ Consider letting your partner know which skill you're using.
```

### 3. 稀缺性原则
**定义：** 由时间限制或有限可用性产生的紧迫感。

**在技能中的应用：**
- 时间限制要求：“在继续之前”
- 顺序依赖：“在 X 之后立即”
- 防止拖延

**使用场景：**
- 即时验证要求
- 时间敏感的工作流
- 防止“我稍后再做”

**示例：**
```markdown
✅ After completing a task, IMMEDIATELY request code review before proceeding.
❌ You can review code when convenient.
```

### 4. 社会认同原则
**定义：** 遵从他人的行为或公认的正常标准。

**在技能中的应用：**
- 通用模式：“每次”、“总是”
- 失败模式：“没有 Y 的 X 必然失败”
- 建立规范

**使用场景：**
- 记录通用实践
- 警告常见失败情况
- 强化标准

**示例：**
```markdown
✅ Checklists without TodoWrite tracking = steps get skipped. Every time.
❌ Some people find TodoWrite helpful for checklists.
```

### 5. 统一性原则
**定义：** 共享身份、“我们感”、群体归属感。

**在技能中的应用：**
- 协作性语言：“我们的代码库”、“我们是同事”
- 共同目标：“我们都想要高质量”

**使用场景：**
- 协作型工作流
- 建立团队文化
- 非层级化实践

**示例：**
```markdown
✅ We're colleagues working together. I need your honest technical judgment.
❌ You should probably tell me if I'm wrong.
```

### 6. 互惠原则
**定义：** 回报所获利益的责任感。

**应用方式：**
- 谨慎使用——可能显得操纵性强
- 技能中很少需要

**避免使用场景：**
- 几乎总是避免（其他原则更有效）

### 7. 喜好原则
**定义：** 偏好与自己喜欢的人合作。

**应用方式：**
- **不要用于合规要求**
- 与诚实反馈文化冲突
- 会导致阿谀奉承

**避免使用场景：**
- 强制执行规范时始终避免

## 按技能类型组合原则

| 技能类型 | 推荐使用 | 避免使用 |
|------------|-----|-------|
| 强制执行规范类 | 权威 + 承诺 + 社会认同 | 喜好、互惠 |
| 指导/技术类 | 适度权威 + 统一 | 过度权威 |
| 协作类 | 统一 + 承诺 | 权威、喜好 |
| 参考类 | 仅清晰度 | 所有说服原则 |

## 生效原理：心理学基础

**明确规则减少合理化借口：**
- “你必须”消除决策疲劳
- 绝对化语言消除“这是例外吗？”的疑问
- 明确的反合理化应对措施堵上特定漏洞

**执行意图创造自动行为：**
- 清晰的触发条件 + 要求的行动 = 自动执行
- “当 X 时，做 Y”比“通常做 Y”更有效
- 降低合规的认知负荷

**LLM 是类人存在：**
- 训练数据包含人类文本的这些模式
- 训练数据中权威语言先于合规行为
- 承诺序列（陈述 → 行动）频繁出现
- 社会认同模式（人人都做 X）建立规范

## 伦理使用

**合理用途：**
- 确保关键实践被遵守
- 创建有效的文档
- 防止可预测的失败

**不合理用途：**
- 为个人利益操纵
- 制造虚假紧迫感
- 基于愧疚感的合规

**检验标准：** 如果用户完全理解该技术，它是否符合用户的真实利益？

## 研究引用

**Cialdini, R. B. (2021).** *《影响力：说服的心理学（新版）》*，Harper Business。
- 七大说服原则
- 影响力研究的实证基础

**Meincke, L. 等人（2025）。** 《叫我混蛋：说服 AI 遵守令人反感的要求》，宾夕法尼亚大学。
- 在 28000 次 LLM 对话中测试了 7 种原则
- 使用说服技术后合规率从 33% 提升至 72%
- 权威、承诺、稀缺性原则最有效
- 验证了 LLM 行为的类人模型

## 快速参考

设计技能时，问自己：

1. **它属于什么类型？**（规范执行类 vs. 指导类 vs. 参考类）
2. **我想改变什么行为？**
3. **适用哪些原则？**（规范执行类通常用权威 + 承诺）
4. **我组合了太多原则吗？**（不要使用全部七种）
5. **这符合伦理吗？**（是否符合用户的真实利益？）

# Mainstream Issue Trackers Only

The setup-project, to-issues, to-prd, and triage skills only support:
- GitHub Issues (via `gh` CLI)
- GitLab Issues (via `glab` CLI)
- Local markdown files (`.scratch/` convention)

Other tools (Jira, Linear, Trello, Asana, etc.) are not supported. Workflow descriptions for "other" trackers are recorded as freeform prose.

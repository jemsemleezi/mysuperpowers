# Gemini CLI Tool Mapping

When skills reference tools not available in Gemini CLI, use these equivalents:

| Claude Code Tool | Gemini CLI Equivalent |
|---|---|
| `TodoWrite` | Use `todowrite` tool |
| `Task` with subagents | Use Gemini's subagent system |
| `Skill` tool | Use `activate_skill` or `skill` tool |
| `Read`, `Write`, `Edit` | Use native Gemini tools |
| `Bash` | Use native Gemini tools |
| `Grep` / `Glob` | Use native search tools |
